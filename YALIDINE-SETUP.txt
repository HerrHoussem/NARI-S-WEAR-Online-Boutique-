NARI'S WEAR — Yalidine Integration Setup

FILES TO REPLACE
1. Replace the root index.html with the included index.html.
2. Replace admin/index.html with the included admin/index.html.
3. Keep all other website files unchanged.

SUPABASE DATABASE
1. Open Supabase > SQL Editor > New query.
2. Paste the full content of yalidine-migration.sql.
3. Click Run.

SUPABASE EDGE FUNCTION
Install the Supabase CLI, log in, and from your project folder run:

  supabase functions deploy yalidine

The function source must be located at:
  supabase/functions/yalidine/index.ts

ADD YALIDINE SECRETS
Get your API ID and API token from your Yalidine merchant account, then run:

  supabase secrets set YALIDINE_API_ID="YOUR_API_ID"
  supabase secrets set YALIDINE_API_TOKEN="YOUR_API_TOKEN"
  supabase secrets set YALIDINE_FROM_WILAYA="YOUR_ORIGIN_WILAYA"

Optional, only if Yalidine provides a different API base URL:
  supabase secrets set YALIDINE_API_BASE="https://api.yalidine.app/v1"

HOW IT WORKS
Customer:
Wilaya > shipping price > Home/StopDesk > commune/address or StopDesk > order saved.

Admin:
Orders > Create shipment > secure Edge Function > Yalidine > tracking saved in Supabase.

IMPORTANT
- Never put the Yalidine API token in index.html, admin HTML, config.js, or GitHub.
- The Yalidine API credentials remain only in Supabase secrets.
- The Create shipment button requires the logged-in account to exist in admin_users.
- Existing older orders may not contain commune/address/StopDesk data and cannot be sent until those fields are filled.
