# Instagram gallery update

Implemented:

- Six real optimized gallery images
- Responsive 3-column desktop / 2-column mobile layout
- Image zoom and dim effect on hover
- Fullscreen lightbox on click
- Escape key and outside-click close behavior
- Direct link to `@naris_wear`
- French and Arabic description updates

The gallery is manual and API-free, which is faster and more reliable on GitHub Pages.
Replace the six WebP files in `assets/images/instagram/` whenever you want to update the gallery.
